 ## <a id="part8"> 8. Установка и базовая настройка сервиса SSHD</a>

 - Установим службу SSHd.
![установка sshd](./images/DO1P8установка.png)

- автостарт службы при загрузке системы
![автостарт](./images/DO1P8автозапуск.png)

- SSHd на порт 2022
Для этого нужно отредактировать файл /etc/ssh/sshd_config, найти строку Port 22, заменить её на Port 2022, перезапустить службу SSH sudo systemctl restart ssh

- 
![ps](./images/DO1P8покажитепроцессы.png)
1. a - выводит список всех процессов
2. u - включая процессы других пользователей
3. x - процессы, не привязанные к терминалу 
4. | - передаёт вывод одной команды ( ps aux ) на вход другой (grep)
5. grep - команда для поиска строк по шаблону
6. [s]sh - это регулярное выражение, где [s] означает "любой символ, который является 's'"

- Перезагрузим систему
![перезагрузим](./images/DO1P8netstat.png)
- tan — это комбинация трех опций:
1. t — отображать TCP соединения
1. a — отображать все соединения (активные и ожидающие)
1. n — показывать адреса и порты в числовом виде

- Значение каждого столбца вывода
1. Proto — Протокол (tcp, tcp6, udp, udp6)
1. Recv-Q — Размер очереди полученных данных, ожидающих обработки приложением (в байтах)
1. Send-Q — Размер очереди данных, готовых к отправке (в байтах)
1. Local Address — Локальный адрес и порт (наш компьютер)
1. Foreign Address — Удаленный адрес и порт (подключенный компьютер)
1. State — Состояние TCP-соединения

- 0.0.0.0 — служба прослушивает на всех сетевых интерфейсах (всех IP-адресах) этого компьютера
